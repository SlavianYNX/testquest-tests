# TestQuest — Калькулятор смет: Тестовая документация и автотесты

## Описание проекта

Данный репозиторий содержит комплект тестовой документации и автоматизированных тестов для веб-приложения **TestQuest — Калькулятор смет** (стенд: https://testquest.pryaniky.com/).

Объект тестирования: раздел **«Продажи» → «Калькулятор смет»** ПО «Бублики».

## Структура репозитория

```
.
├── README.md                     # Этот файл
├── docs/
│   └── TestPlan.md               # План тестирования
├── test-cases/
│   └── TestCases.md              # Тест-кейсы (10+ кейсов)
├── tests/
│   ├── conftest.py               # Фикстуры pytest
│   ├── test_calculator.py        # Автотесты калькулятора
│   └── requirements.txt          # Зависимости Python
├── run-tests.sh                  # Скрипт запуска для Linux/macOS
└── run-tests.bat                 # Скрипт запуска для Windows
```

## Требования к окружению

- **Python 3.8+**
- **pip** (менеджер пакетов Python)
- **Веб-браузер** (Chrome, Firefox или Edge — будет установлен автоматически)

## Установка зависимостей

Зависимости устанавливаются автоматически при запуске скрипта `run-tests.sh` или `run-tests.bat`.

При необходимости можно установить вручную:

```bash
pip install -r tests/requirements.txt
playwright install
```

## Запуск тестов

### Linux / macOS

```bash
BASE_URL=https://testquest.pryaniky.com ./run-tests.sh
```

### Windows

```bat
set BASE_URL=https://testquest.pryaniky.com
run-tests.bat
```

Если переменная `BASE_URL` не указана, используется значение по умолчанию: `https://testquest.pryaniky.com`.

## Результат запуска

После завершения тестов вы увидите:

- Подробный вывод по каждому тесту (PASSED / FAILED)
- Итоговый результат: **PASSED** или **FAILED**
- Код выхода: `0` — все тесты пройдены, `≠0` — есть неудачные тесты

Пример вывода:

```
============================= test session starts ==============================
collected 10 items

tests/test_calculator.py::test_meta_kp_fields_present PASSED             [ 10%]
tests/test_calculator.py::test_tariff_cloud_selection PASSED             [ 20%]
...

========================= 10 passed in 45.67s ==========================
RESULT: PASSED
Exit code: 0
```
