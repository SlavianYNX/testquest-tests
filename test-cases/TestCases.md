# Тест-кейсы: TestQuest — Калькулятор смет

## TC-001: Проверка отображения полей мета-данных КП

**Название:** Проверка наличия и доступности всех полей мета-данных коммерческого предложения

**Предусловие:**
- Пользователь открыл страницу https://testquest.pryaniky.com/
- Активен раздел «Калькулятор смет»

**Шаги:**
1. Проверить наличие поля «Компания» (input с id `companyName`)
2. Проверить наличие поля «Дата выставления КП» (input type=date с id `kpIssueDate`)
3. Проверить наличие поля «КП действительно до» (input type=date с id `kpValidUntil`)
4. Проверить наличие поля «Название проекта» (input с id `projectName`)
5. Проверить наличие выпадающего списка «Менеджер» (select с id `kpManager`)
6. Проверить, что все поля доступны для взаимодействия

**Ожидаемый результат:**
- Все 5 полей присутствуют на странице
- Поля доступны для ввода/выбора
- Выпадающий список «Менеджер» содержит минимум 3 варианта

## TC-002: Выбор тарифа «TestQuest Облако» (SAAS)

**Название:** Переключение на тариф SAAS и проверка отображения блока облака

**Предусловие:**
- Пользователь находится на странице калькулятора
- Вкладка «Модули» активна

**Шаги:**
1. Нажать на радио-кнопку «TestQuest Облако» (value="cloud")
2. Дождаться обновления интерфейса
3. Проверить отображение блока «TestQuest Облако (SAAS)»

**Ожидаемый результат:**
- Активен тариф «Облако»
- Отображается блок `estimate-cloud-block`
- Блок «Коробка» скрыт

## TC-004: Ввод количества пользователей

**Название:** Проверка расчёта стоимости при вводе количества лицензий

**Предусловие:**
- Выбран тариф «Облако» или «Коробка»
- Вкладка «Модули» активна

**Шаги:**
1. В поле «Количество пользователей» ввести значение 500
2. Нажать кнопку «Применить» или дождаться авто-расчёта
3. Проверить отображение суммы в блоке итогов

**Ожидаемый результат:**
- Количество пользователей сохранено
- Сумма пересчитана с учётом прогрессивной скидки за объём
- При 500 пользователях применяется делитель 1.5

---

## TC-005: Выбор срока лицензии и проверка скидки

**Название:** Проверка применения скидки за срок лицензии

**Предусловие:**
- Выбран тариф
- Введено количество пользователей > 0

**Шаги:**
1. Открыть вкладку «Срок лицензии»
2. Выбрать срок 6 месяцев
3. Запомнить сумму
4. Выбрать срок 12 месяцев
5. Сравнить сумму с шагом 3

**Ожидаемый результат:**
- При сроке 6 месяцев применяется скидка 10%
- При сроке 12 месяцев применяется скидка 20%
- Сумма при 12 месяцах меньше, чем при 6 (с учётом скидки)

---

## TC-006: Выбор модулей из разных групп

**Название:** Проверка добавления опциональных модулей в смету

**Предусловие:**
- Активна вкладка «Модули»

**Шаги:**
1. Развернуть группу «Ключевые модули»
2. Отметить чекбокс «Конструктор процессов»
3. Отметить чекбокс «Корпоративный университет»
4. Развернуть группу «Дополнительные модули»
5. Отметить чекбокс «Календарь отпусков»
6. Проверить панель «Выбранные модули»

**Ожидаемый результат:**
- Выбранные модули отображаются в панели «Выбранные модули»
- Применяются коэффициенты за группы модулей (0.2 за ключевые, 0.1 за дополнительные)
- Итоговая сумма увеличивается

## TC-007: Добавление услуг внедрения

**Название:** Проверка добавления услуг внедрения с фиксированной ценой

**Предусловие:**
- Активна вкладка «Внедрение»

**Шаги:**
1. Развернуть группу «ПРОЕКТИРОВАНИЕ»
2. Отметить услугу «Подготовка технического задания»
3. Развернуть группу «РАЗРАБОТКА»
4. Отметить услугу «Документация»
5. Проверить панель выбранных услуг

**Ожидаемый результат:**
- Услуги отображаются в списке выбранных
- Цены соответствуют прайсу (117000 руб. за ТЗ, 58500 руб. за документацию)
- Сумма внедрения добавляется к общей сумме

---

## TC-008: Расчёт Time & Material

**Название:** Проверка добавления и расчёта услуг по модели T&M

**Предусловие:**
- Активна вкладка «Внедрение»
- Выбрана группа с услугами T&M

**Шаги:**
1. В секции Time & Material ввести количество часов: 100
2. Проверить ставку в час (по умолчанию 5850 руб.)
3. Нажать «Добавить в смету»
4. Проверить итоговую сумму T&M

**Ожидаемый результат:**
- Сумма T&M = 100 × 5850 = 585 000 руб.
- Услуга отображается в разделе T&M
- Сумма включается в ИТОГО

---

## TC-009: Проверка итоговой суммы (ИТОГО)

**Название:** Сверка итоговой суммы со всеми компонентами сметы

**Предусловие:**
- Заполнены все разделы: тариф, модули, внедрение, T&M

**Шаги:**
1. Записать стоимость тарифа (Облако/Коробка)
2. Записать стоимость модулей (с коэффициентами)
3. Записать стоимость услуг внедрения
4. Записать стоимость T&M
5. Посчитать ожидаемую сумму вручную
6. Сравнить с отображаемой суммой ИТОГО

**Ожидаемый результат:**
- Сумма ИТОГО равна сумме всех компонентов
- Расхождение не более 1 руб. (округление)

---

## TC-010: Выгрузка сметы в Excel

**Название:** Проверка генерации и скачивания файла Excel со сметой

**Предусловие:**
- Заполнена смета (минимум: компания, тариф, пользователи, 1 модуль)

**Шаги:**
1. Нажать кнопку «Выгрузить смету в Excel»
2. Дождаться завершения генерации
3. Проверить появление файла в загрузках
4. Открыть файл в Excel/LibreOffice
5. Проверить наличие данных и цветовой маркировки

**Ожидаемый результат:**
- Файл .xlsx скачан
- В файле присутствуют все данные из сметы
- Зелёным выделены подставленные значения
- Красным выделены поля для ручной проверки
- Чёрным — значения, которые не нужно менять

---

## TC-011: Валидация обязательных полей

**Название:** Проверка блокировки выгрузки при незаполненных обязательных полях

**Предусловие:**
- Страница калькулятора открыта
- Ни одно поле не заполнено

**Шаги:**
1. Нажать кнопку «Выгрузить смету в Excel» без заполнения полей
2. Проверить наличие сообщения об ошибке
3. Заполнить только название компании
4. Снова нажать кнопку выгрузки

**Ожидаемый результат:**
- При пустых обязательных полях выгрузка блокируется
- Отображается hint с требованием заполнить поля
- Минимум для выгрузки: компания, тариф, количество пользователей

---

## TC-012: Интеграция с разделом «Счета»

**Название:** Проверка передачи данных из калькулятора в счёт

**Предусловие:**
- Заполнена смета в калькуляторе
- Есть переход в раздел «Счета»

**Шаги:**
1. Заполнить данные КП в калькуляторе
2. Перейти в раздел «Счета»
3. Проверить подстановку данных заказчика
4. Сформировать счёт (.docx)

**Ожидаемый результат:**
- Данные компании подставляются в счёт
- Сумма из сметы переносится в счёт
- Файл .docx генерируется корректно
